## 공통 사항

- 모든 교재가 같은 틀입니다: `개념 정리 → 예제·유제 → Level 1 기초 → Level 2 기본 → Level 3 실력 → 대표 기출`
- 개념은 짝수 쪽, 예제·유제는 홀수 쪽에 배치됩니다(강 대부분이 16쪽 구성).
- 본문은 p.101 에서 끝나고 그 뒤는 **정답과 풀이**입니다.
- 문항코드(`[26008-XXXX]` 등)로 EBS<i>i</i> 푸리봇 해설 검색이 됩니다.

## 텍스트를 뽑을 때

`pypdf` 는 커스텀 폰트 인코딩 때문에 한글이 전부 깨집니다. **PyMuPDF(fitz)** 를 쓰세요.

```python
import fitz
doc = fitz.open(r"D:\test1234\01_원본자료\수학1\2027 수능특강 수학 I.pdf")
print(doc[3].get_text())   # p.4
```

수식은 한글 워드프로세서식 약물로 나옵니다: `;2!;` = ½, `Û` = 제곱, `n'a` = ⁿ√a
