## 설계

**슬라이드는 개념 설명 전용입니다.** 교재의 예제·유제 문항은 싣지 않았습니다.
문제는 교재를 펴고 풀게 하고, 슬라이드는 개념과 시각화만 담당합니다.

**디자인과 동작은 6개 강이 공유합니다.** `00_공통/02_서식_스타일/slide.css` 와 `slide.js`
한 곳을 고치면 모든 강에 반영됩니다. manim 색도 `00_공통/01_템플릿/slide_theme.py`
한 곳에서 관리되며 CSS 의 `:root` 와 짝을 이룹니다. **한쪽만 바꾸면 톤이 어긋납니다.**

**수식은 KaTeX 를 로컬에 두고 씁니다.** 인터넷 없이도 교실에서 뜹니다.

## 영상 다시 만들기

```powershell
# 한 강 전체 (1080p)
00_공통\01_템플릿\build_manim.ps1 -SceneFile "...\05_자료\manim\k03_scenes.py"

# 한 장면만 빠르게 (480p)
00_공통\01_템플릿\build_manim.ps1 -SceneFile "...\k03_scenes.py" `
  -Scenes S1Radian -Quality preview
```

렌더된 mp4 는 해당 강의 `02_강의안/media/` 로 자동 복사되므로 HTML 은 손댈 필요가 없습니다.

### 필요한 도구

| 도구 | 용도 | 비고 |
|---|---|---|
| Python + manim | 영상 렌더링 | `pip install manim imageio-ffmpeg importlib_metadata` |
| ffmpeg | 인코딩 | `imageio-ffmpeg` 에 포함된 바이너리를 씁니다 |
| MiKTeX | `MathTex` 조판 | `winget install MiKTeX.MiKTeX` |

경로는 `build_manim.ps1` 상단의 `$Venv`, `$MikTeX` 두 줄에 있습니다. 다른 PC 로 옮기면 이 둘만 고치면 됩니다.

## AI 도구

`.env.example` 을 `.env` 로 복사하고 [AI Studio](https://aistudio.google.com/apikey) 키를 넣어야 동작합니다.

```powershell
# 슬라이드 디자인 다시 만들기 (Gemini)
python 00_공통\01_템플릿\ai_redesign.py "<슬라이드.html>" --brief "더 차분하게"

# 강의자료 검수 (Antigravity)
python 00_공통\01_템플릿\ai_review.py --lesson 03 --focus math

# 각 강 README 자동 생성
python 00_공통\01_템플릿\make_readme.py
```

`ai_redesign.py` 는 받은 CSS 에서 **선택자가 하나라도 사라지면 적용을 거부**합니다.
레이아웃이 깨진 채 덮어쓰이지 않습니다.

교재에서 본문을 뽑을 때 `pypdf` 는 커스텀 폰트 인코딩 탓에 한글이 전부 깨집니다.
**PyMuPDF(fitz)** 를 쓰세요. 자세한 내용은 [`01_원본자료/README.md`](01_원본자료/README.md).

> **미적분 교재는 텍스트 레이어가 없는 스캔 PDF** 입니다. 본문 추출이 안 되므로
> 강의자료를 만들려면 OCR 이 필요합니다.
