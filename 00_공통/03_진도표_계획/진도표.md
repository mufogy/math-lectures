# 2027 EBS 수능특강 수학Ⅰ 진도표 (고2)

- 교재: 2027학년도 EBS 수능특강 수학Ⅰ (총 160쪽 / 본문 p.4~101, 정답과 풀이 p.102~160)
- 구성: 6개 강, 강마다 `개념 정리 → 예제·유제 → Level 1 기초 → Level 2 기본 → Level 3 실력 → 대표 기출`
- 편성: **주 4차시 기준 총 42차시 ≒ 11주**
- 차시 설계 원칙: 개념 세트(개념 1쪽 + 예제·유제 1쪽) = 1차시, 강마다 문제풀이 2차시
